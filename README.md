# Asociación Argos

Diseño y desarrollo de una web estática para una asociación ficticia dedicada
al rescate, cuidado y adopción de perros y gatos.

Este proyecto se ha creado como ejemplo de trabajo para mostrar conocimientos
de diseño y desarrollo frontend.

> **Estado del proyecto:** La web se encuentra actualmente en desarrollo y
> todavía no está terminada. Algunas secciones y funcionalidades pueden estar
> pendientes de completar o mejorar.

## Sobre el proyecto

La web presenta la identidad visual de la Asociación Argos y permite consultar
información sobre:

- La historia, el equipo y los colaboradores de la asociación.
- Perros y gatos disponibles para adopción.
- Las diferentes formas de colaborar: adopción, apadrinamiento, donaciones,
  voluntariado y alta como socio.
- Los datos de contacto y la suscripción a una newsletter.

El diseño incluye un menú de navegación, páginas multipágina, formularios,
animaciones, un carrusel de animales y un modo claro/oscuro.

> **Aviso:** La Asociación Argos es completamente ficticia. Cualquier parecido
> con una asociación, persona, animal o situación real es pura coincidencia.

## Tecnologías utilizadas

- HTML5
- CSS3
- Sass/SCSS
- JavaScript
- Bootstrap 5.3 mediante CDN

## Estructura del proyecto

```text
├── inicio.html
├── estilo.css
├── estilo.scss
├── modoNoche.js
├── imagenes/
├── nuestraHistoria/
├── equipo/
├── colaboradores/
├── nuestrosAnimales/
│   ├── perros/
│   └── gatos/
├── colabora/
│   ├── adopta/
│   ├── donaciones/
│   ├── padrino/
│   ├── socio/
│   └── voluntariado/
└── contacto/
```

Los archivos `.scss` contienen los estilos fuente y los archivos `.css`
compilados son los que utiliza directamente el navegador.

## Visualización

Para ver el proyecto, abre `inicio.html` en un navegador. También se puede
utilizar la extensión **Live Server** de Visual Studio Code para ejecutarlo
localmente.

Bootstrap se carga desde jsDelivr, por lo que es necesaria una conexión a
Internet para que se visualicen correctamente todos sus estilos y componentes.
